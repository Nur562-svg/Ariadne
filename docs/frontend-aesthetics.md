# Ariadne 前端审美规范

给 zcode / 任何写 UI 的工具：先读再动手。产品是考前书桌，不是营销落地页。

## 动手前

1. **Purpose** — 谁在时间压力下盯着这块屏？它帮什么决策或回忆？
2. **Tone（固定）** — Editorial / 精炼书桌。安静、可信。禁止 maximalist chaos、玩具风、赛博海报、紫渐变 SaaS 默认皮。
3. **Constraints** — Next.js + Tailwind + TypeScript；正文对比 ≥4.5:1（WCAG AA）；可键盘操作；动效不得挡住阅读。
4. **Differentiation** — 记住一根脊梁：**平静纸面/墨色上的朱砂**、清晰实体原子、证据优先的 cite。不是「又一个 AI 刷题站」。

方向要清晰，执行要准。克制就是大胆。

## 品牌硬规则

- **朱砂是唯一品牌强调色**：亮色 `#b8432f`，暗色 `#e0705a`。禁止第二个品牌强调色抢戏。
- **一种视觉处理 ↔ 一种含义**（颜色、字重、chip、左边线）。禁止同一套样式表达两件不同的事。
- 表面色 / 墨色 / muted / accent / danger·success 用 CSS 变量，语义稳定。
- 允许亮色与暗色主题，必须像同一产品。

## App 布局（Linear 式克制）

产品面默认这套，不是落地页：

- 冷静表面层级；强字体与间距；少色；信息密但可读；铬件极少。
- 组织：**主工作区** + **导航** + **次要上下文/检查器**；朱砂只用于动作或状态强调。
- **卡片只在「卡本身就是交互」时用**；能改成普通分区就不套卡。
- 禁止：仪表盘卡砖拼贴、处处粗边框、常规产品 UI 背后的装饰渐变、多个强调色抢戏、不助扫描的装饰图标。
- 文案用**效用文**：朝向、状态、动作。禁止首页式英雄文案、隐喻口号、营销横幅（除非明确做营销页）。
- **营销落地页**（全幅 hero、海报感）另开 brief；默认不要塞进 `/entities`、阅读器、Clew 面板。

## 该打磨的

- **字体** — 标题可用有性格的 display；正文必须扛得住密排中文 + 拉丁医学词。不要把 Inter / Roboto / Arial / system-ui 当成「设计声线」。不要默认拿 Space Grotesk 凑数。一对 display + 一对精炼 body；发版前先过中文可读性。
- **颜色** — 大面积冷静表面 + 锐利朱砂点缀，胜过平均摊开的怯懦配色。禁止紫白渐变套路、装饰性彩虹渐变。
- **动效** — 优先 CSS。整页最多一次高冲击进场（如 staggered enter）。hover/focus 是为了说清状态，不是娱乐。遵守 `prefers-reduced-motion`。禁止 scroll hijack；测验 / cite 附近禁止持续弹跳。
- **布局** — 阅读层级清楚。卡片与 Clew 笔记周围可以留白；不对称只在改善扫视路径时用。禁止斜切 hero、叠乱、把 cite 藏进破格装饰。
- **氛围** — 轻阴影、发丝边、至多极淡纸感纹理。禁止大面积 grain、自定义光标、抢内容的装饰框。

## 禁止上线

- 通用 AI 审美：Inter 全家桶、紫渐变、没有 Ariadne 性格的 cookie-cutter bento
- 抢走实体卡 / cite / quiz 注意力的视觉噪音
- 未核实 cite 却长得像「已确认」（fail-closed：未核实保持琥珀 / `p.?`）
- 朱砂以外的颜色当品牌铬件
- Anthropic / 他牌品牌色与字体（Poppins+Lora 橙蓝绿等）冒充 Ariadne

## 复杂度匹配愿景

精炼书桌要的是**精度**：间距节奏、字号阶梯、chip 状态、空状态——不是特效堆叠。帮不了学生找到或信任一个原子的花活，删。

## 验收清单

- [ ] 一眼是 Ariadne 书桌，不是通用 AI 模板
- [ ] 朱砂是唯一品牌强调色；语义不歧义
- [ ] 全部正文对比 ≥4.5:1
- [ ] 中文 + 拉丁医学串在 body 尺寸仍可读
- [ ] 动效不拖延、不干扰主阅读 / 测验路径；尊重 `prefers-reduced-motion`
- [ ] 产品面无营销 hero / 卡砖仪表盘默认皮
- [ ] `pnpm build` 通过；不为装饰硬加依赖
- [ ]（可选）按 Vercel Web Interface Guidelines 做 `file:line` 审查

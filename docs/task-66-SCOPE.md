## honesty 合同（硬 · 铁 · 写进每个字母）

1. **只读答**：本刀 Clew 路径 **只**返回对话文本（±可选结构化「建议补丁」JSON 供复制）。**禁止**服务端或客户端自动写 `data/cards/*.entities.json` / `blocks.json` / config / `verified:true`。  
2. **剪贴板-only 带走**：若提供「复制建议补丁」——形状对齐 `ariadne.atom-draft-patch.v1`（或等价只读建议文档）；用户自行粘贴到编辑器/草稿流程；**禁止**按钮一键 `setDraft`/`PATCH`/`writeFile`。T55 `suggestQuote` 同族契约。  
3. **永不 bulk**：单次请求 = **一问** + **当前书桌上下文**（书/章/页/卡名/`citePages`；可选当前页 OCR **截断**小窗）。**禁止**整章/多章/全书循环 parse·extract·ingest；API 拒收 `chapters[]` 批量、拒收 extract/parse 作业形 payload。  
4. **fail-closed**：缺 `ZHIPU_API_KEY`/`MINIMAX_API_KEY`（或所选 provider 钥）→ 明确失败或降 **诚实 stub**（保留「stub · 未接模型」族文案），**禁止**编假答案冒充 live。上游错 → 可见错误 + 保留用户问题。  
5. **不做诊断 / 不装已核**：系统提示 + UI 脚注：不做医疗诊断；回答 ≠ seed verified ≠ heye 已对 ≠ study 已练。页码只引用请求上下文已给页；模型自造页码须标「未核验」或不采信。  
6. **钥安全**：钥只进 **服务端** env；**禁止**写入仓库、docs 正文、客户端 bundle、`NEXT_PUBLIC_*`。本 SCOPE / paste **不**粘贴任何 key 值。  
7. **不 redo Clew 壳**：三 tab（对话|本轮变更|复习队列）、Changes/Queue、return 短链、`buildSuggestions` 静态建议问、LocalProgressStrip compact **形状保留**；本刀扩展 **发送/答面**，不拆壳。  
8. **不 redo T54–T65**：禁止重写质量算法 / DraftInbox / cockpit / seed-apply / AtomDraftEditor / shelf 诚实文案。  
9. **小能力优先**：一档可用模型即可（Zhipu **或** Minimax openai-compatible）；**禁止**本刀交三档选择器 + 配额系统 + LiteLLM 网关全量 densify（那些属后续 harness 刀）。  
10. **精炼**：无营销英雄；无新「一键写回」朱砂主 CTA；答面效用文。
